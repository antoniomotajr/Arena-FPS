# Arena FPS

Jogo FPS no navegador (PC e celular). Arquivo único: `index.html` (CSS, JavaScript e three.js embutidos, funciona offline).

## Publicar no GitHub Pages
1. Crie um repositório e envie `index.html`, `.nojekyll` e este `README.md`
   (Add file → Upload files).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
3. Em ~1 minuto o jogo abre em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

No celular, abra o link no Chrome; o jogo entra em tela cheia ao tocar.
